# DeployGuard

A self-hosted progressive delivery platform for Docker-based applications.

DeployGuard enables developers to perform canary deployments,
blue-green deployments, automated health checks, and rollbacks
on Docker Compose and VPS infrastructure without Kubernetes.

## Tech Stack

- React + TypeScript
- Node.js + Express + TypeScript
- PostgreSQL + Prisma
- Redis + BullMQ
- Docker + Docker Compose
- Nginx
- Prometheus
- GitHub Actions

## Project Structure

- frontend: Web dashboard
- backend: Control Plane API
- agent: Deployment agent
- packages: Shared packages
- infrastructure: Docker, Nginx, and monitoring configurations
- docs: Technical documentation
